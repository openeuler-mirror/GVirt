# 文档规范目录

本目录（`doc/conventions/`）仅存放 xlite 文档的编写规范，不存放流程图与架构文档（模型架构 forward 流程图见 [doc/developer_guide/models/](../developer_guide/models/)；单算子等通用图的绘制规则同样遵循本目录的 [图示规范](diagram_conventions.md)）。

## 目录内容

| 文件 | 说明 |
|------|------|
| [diagram_conventions.md](diagram_conventions.md) | **图示规范** —— 格式选择、配色 / 形状 / 箭头约定、shape 记号表、提交 checklist。[developer_guide/models/](../developer_guide/models/) 下的模型文档均链接本规范，新增流程图前必读 |
