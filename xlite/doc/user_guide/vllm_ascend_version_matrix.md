# xlite × vllm-ascend 版本对照表

xlite 以 dev 依赖形式（vllm-ascend 侧 `requirements-dev.txt`）随版本发布，自 v0.12.0rc1（2025-12-13）引入，初期未锁定版本号，自 v0.13.0rc2 起固定版本。

vllm-ascend 发布版本与其依赖的 xlite 版本对应关系如下（按发布态统计，同一 xlite 版本归并为一行）：

| vllm-ascend 版本                            | 发布时间              | xlite 版本        |
| ------------------------------------------- | --------------------- | ----------------- |
| v0.12.0rc1 / v0.13.0rc1                     | 2025-12-13 ~ 12-27    | `xlite`（未锁版） |
| v0.13.0rc2 / v0.13.0rc3 / v0.13.0           | 2026-01-24 ~ 04-24    | 0.1.0rc0          |
| v0.14.0rc1 / v0.15.0rc1                     | 2026-01-26 ~ 02-27    | 0.1.0rc1          |
| v0.16.0rc1 / v0.17.0rc1 / v0.18.0rc1 / v0.18.0 | 2026-03-10 ~ 04-30 | 0.1.0rc3          |
| v0.19.1rc1                                  | 2026-04-30            | 0.1.0rc4          |
| v0.20.2rc1                                  | 2026-06-03            | 0.1.0rc9.dev210   |
| v0.21.0rc1                                  | 2026-06-12            | 0.1.0rc10.dev210  |
| v0.22.1rc1 / v0.23.0 / v0.23.0.post1 / v0.24.0rc1 | 2026-06-30 ~ 09-22 | 0.1.0rc11.dev210 |

| v0.33.0rc（开发分支，未发版）               | —（至今 2026-11-21） | 0.2.0rc5   |

注：

1. 数据来源：vllm-ascend 各发布 tag 的 `requirements-dev.txt`（发布态）；发布时间取 tag 创建日期。
2. release 分支可能在对应 tag 发售后继续升级 xlite 依赖，且不随 tag 发布。例：`releases/v0.26.0rc` 分支在 v0.26.0rc2 发售当日将依赖从 0.1.0rc12.dev210 升到 0.2.0rc0（#16506），但 0.2.0rc0 未出现在任何发布 tag 中。本表以发布 tag 为准。
3. xlite 发版节奏与 vllm-ascend 发版节奏不完全一致，因此 vllm-ascend 中使用的 xlite 版本不一定是最新版，最新版请以本仓库为准。
4. vllm-ascend 版本号与上游 vLLM 同名版本严格对齐（官方版本策略），rcN 表示该系列第 N 个候选版（N 可大于 1，如上游 vLLM v0.29.0 曾连发 rc1~rc6）；表内首列为发布 tag 全名。
