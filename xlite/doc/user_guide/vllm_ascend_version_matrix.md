# xlite × vllm-ascend 版本对照表

xlite 以 dev 依赖形式（vllm-ascend 侧 `requirements-dev.txt`）随版本发布，自 v0.13.0 引入。

vllm-ascend 发布版本与其依赖的 xlite 版本对应关系如下：

| vllm-ascend 版本                            | 发布时间           | xlite 版本       |
| ------------------------------------------- | ------------------ | ---------------- |
| ≤ v0.11.0                                  | —                 | 无（未引入）     |
| v0.13.0                                     | 2026-02-05         | 0.1.0rc0         |
| v0.18.0                                     | 2026-04-30         | 0.1.0rc3         |
| v0.20.2rc                                   | 2026-06-03         | 0.1.0rc9.dev210  |
| v0.21.0rc                                   | 2026-06-12         | 0.1.0rc10.dev210 |
| v0.22.1rc / v0.23.0（.post1）/ v0.24.0rc    | 2026-06-30 ~ 09-22 | 0.1.0rc11.dev210 |
| v0.25.1rc                                   | 2026-08-19         | 0.1.0rc12.dev210 |
| v0.26.0rc                                   | 2026-09-16         | 0.2.0rc0         |
| v0.27.1rc / v0.28.0rc / v0.29.0rc / v0.30.0 | 2026-09-25 ~ 10-16 | 0.2.0rc1         |

注：

1. 数据来源：vllm-ascend 各 `releases/*` 分支的 `requirements-dev.txt`；发布时间取 tag 创建日期，v0.30.0 无正式 tag、取分支最新提交日期。
2. xlite 发版节奏与 vllm-ascend 发版节奏不完全一致，因此 vllm-ascend 中使用的 xlite 版本不一定是最新版，最新版请以本仓库为准。
